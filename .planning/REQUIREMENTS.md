# Requirements: Numero (Next Gen)

**Defined:** 2026-02-01
**Core Value:** Delivering deeply personalized, AI-driven numerological insights in a visually stunning, friction-free experience.

## v1 Requirements

### Core Numerology (Ported & Enhanced)
- [ ] **CORE-01**: User can enter DOB/Name and view grid calculations (Moolank/Bhagyank)
- [ ] **CORE-02**: User can view standard interpretations for their numbers
- [ ] **CORE-03**: User can save their profile locally (no cloud sync for v1)

### Immersive UI (Frontend Rewrite)
- [ ] **UI-01**: User experiences smooth page transitions (Motion)
- [ ] **UI-02**: User interacts with animated numerology grids (not static tables)
- [ ] **UI-03**: User can toggle between Light and Dark cosmic modes

### AI-First Experience
- [ ] **AI-01**: User receives a personalized Daily Forecast generated by AI
- [ ] **AI-02**: User can generate an AI-enhanced PDF report
- [ ] **AI-03**: User can view AI-driven compatibility analysis between two profiles

## v2 Requirements (Deferred)

### AI Features
- **AI-CHAT**: Conversational numerologist persona (Chatbot)
- **AI-MONTHLY**: Monthly deep-dive forecasts

### Social & Engagement
- **SOC-01**: Social Sharing (Share charts/forecasts as images)
- **SOC-02**: Cloud Profile Management (Sync across devices)
- **SOC-03**: Premium Subscription Flow (Payment integration)

## Out of Scope
| Feature | Reason |
|---------|--------|
| Community Forums | High complexity, moderation load, not core to personal insight |
| Friend Graph | Focus on direct compatibility first, network effects later |
| Legacy UI Support | Total rewrite; old UI is deprecated |
