<task type="auto">
  <name>Task 2: Configure Biome for formatting and linting</name>
  <files>
    package.json
    biome.json
    .husky/pre-commit
  </files>
  <action>
Replace ESLint + Prettier with Biome (single tool, 100x faster).

Steps:
1. Install Biome and Husky:
   ```bash
   cd /Users/deepaknaik/code/numero
   pnpm add -D @biomejs/biome husky
   ```
2. Initialize Husky:
   ```bash
   pnpm exec husky init
   ```
3. Remove old tooling (Next.js scaffolds with ESLint):
   ```bash
   pnpm remove eslint eslint-config-next
   rm -f .eslintrc.json
   ```
4. Create biome.json configuration:
   ```json
   {
     "$schema": "https://biomejs.dev/schemas/1.9.0/schema.json",
     "vcs": {
       "enabled": true,
       "clientKind": "git",
       "useIgnoreFile": true
     },
     "files": {
       "include": ["src/**/*.ts", "src/**/*.tsx", "*.ts", "*.mjs"],
       "ignore": ["node_modules", ".next", "dist", ".legacy-app"]
     },
     "formatter": {
       "enabled": true,
       "indentStyle": "space",
       "indentWidth": 2,
       "lineWidth": 100
     },
     "linter": {
       "enabled": true,
       "rules": {
         "recommended": true,
         "suspicious": {
           "noExplicitAny": "error"
         }
       }
     },
     "javascript": {
       "formatter": {
         "semicolons": "asNeeded",
         "quoteStyle": "double"
       }
     }
   }
   ```
5. Update package.json scripts (replace ESLint scripts):
   ```json
   {
     "scripts": {
       "dev": "next dev",
       "build": "next build",
       "start": "next start",
       "lint": "biome check .",
       "lint:fix": "biome check --write .",
       "format": "biome format --write .",
       "type-check": "tsc --noEmit"
     }
   }
   ```
6. Configure pre-commit hook (.husky/pre-commit):
   ```bash
   #!/usr/bin/env sh
   pnpm biome check --write --staged
   ```
7. Make pre-commit executable:
   ```bash
   chmod +x .husky/pre-commit
   ```
8. Run initial format:
   ```bash
   pnpm format
   ```

**Why remove ESLint:** Biome provides faster linting with same rule coverage. ESLint + Prettier combo is legacy approach.

**Why staged files only in hook:** Prevents formatting unrelated files during commit.
  </action>

    2. `cat biome.json | grep -q "noExplicitAny"` - Config exists with strict rules

    4. `cat .husky/pre-commit | grep -q "biome"` - Pre-commit hook configured
    5. Test hook: Make a small change to src/app/page.tsx, stage it, commit - Biome should auto-format
