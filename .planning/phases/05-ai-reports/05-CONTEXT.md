# Phase 05: AI Reports + Compatibility

**Goal:** Implement premium AI-enhanced PDF reports and deep compatibility analysis.

## Strategic Context
While Phase 4 introduced AI for daily engagement, Phase 5 focuses on "deep dive" content—the kind users might pay for or share. We will upgrade the standard numerology report from a static template to a dynamic, personalized narrative generated by Gemini. Similarly, compatibility analysis will go beyond simple score matching to explain the *dynamics* of a relationship.

## Architecture
- **Server Actions**:
  - `generateReport`: Orchestrates data calculation, AI generation, and PDF creation.
  - `analyzeCompatibility`: Performs dual-chart analysis and generates relationship insights.
- **AI Integration**:
  - Reuse `src/lib/ai/gemini.ts` and `rate-limit.ts`.
  - New prompts in `src/lib/ai/prompts.ts` for detailed life reports and relationship synergy.
- **PDF Generation**:
  - Use `pdfkit` (or similar node-based library) on the server side to generate documents.
  - Stream the PDF directly to the client.

## Requirements (AI-02, AI-03)
1. **AI Reports**:
   - Generate a comprehensive text analysis of Moolank, Bhagyank, and Grid.
   - Convert this analysis into a beautifully formatted PDF.
   - Include "Cosmic" branding in the PDF.
2. **Compatibility**:
   - Compare two profiles (User + Partner).
   - Generate an AI interpretation of their synergy (not just "80% compatible", but "Why").

## Dependencies
- `pdfkit`: For PDF generation (already present in legacy `package.json`, need to verify for Next.js).
- `@google/generative-ai`: Existing.
